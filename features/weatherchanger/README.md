# weatherchanger: Weather Changer

Changes the weather and time of day on your screen only; the server's go on underneath. ([ADR 0053](../../docs/adr/0053-visual-and-combat-modules.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Weather | World's own, Clear, Rain, Thunder, Snow | Clear |
| Hold the time | on/off | off |
| Time | 00:00-23:00 | 12:00 |

```sh
./gradlew :features:weatherchanger:check
```
