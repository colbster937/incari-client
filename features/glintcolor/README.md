# glintcolor: Enchant Glint

Colors the enchantment shimmer on items and armor your way. Speed and strength stay the game's accessibility options. Only you see it. ([ADR 0061](../../docs/adr/0061-cosmetics.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Color | color | `#7FC8FF` |

```sh
./gradlew :features:glintcolor:check
```
