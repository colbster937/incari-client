# shortswords: Short Swords

Draws swords smaller in first person, as 1.8 PvP packs did. Reach and hits are unchanged. ([ADR 0062](../../docs/adr/0062-incari-settings-and-the-2026-10-12-batch.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Size | 40-100% | 70% |
| Also while blocking | on/off | on |

```sh
./gradlew :features:shortswords:check
```
