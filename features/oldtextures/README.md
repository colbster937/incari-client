# oldtextures: Old Textures

Turns the game's Programmer Art pack (pre-1.14 textures) on and off, and follows the pack if you switch it in Resource Packs. Each change reloads resources. ([ADR 0055](../../docs/adr/0055-built-in-packs-and-old-textures.md))

No settings besides the toggle key.

```sh
./gradlew :features:oldtextures:check
```
