# freelook: Freelook

Hold (or toggle) the key to look around without turning your player; letting go puts the view back. ([ADR 0053](../../docs/adr/0053-visual-and-combat-modules.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Freelook key | keybind | Left Alt |
| Key | Hold, Toggle | Hold |
| Camera | Behind, In front, First person | Behind |
| Invert up and down | on/off | off |

```sh
./gradlew :features:freelook:check
```
