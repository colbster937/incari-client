# lowshield: Low Shield

Draws your shield lower in first person so it hides less. Blocking is unchanged. ([ADR 0053](../../docs/adr/0053-visual-and-combat-modules.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Lower by | 0-90% of its height | 35% |
| Also while blocking | on/off | on |

```sh
./gradlew :features:lowshield:check
```
