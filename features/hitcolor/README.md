# hitcolor: Hit Color

Changes the red flash of hurt mobs and players to your color. Only you see it. ([ADR 0061](../../docs/adr/0061-cosmetics.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Color | color | `#5AB8FF` |
| Strength | 10-100% | 30%: the game's own strength |

```sh
./gradlew :features:hitcolor:check
```
