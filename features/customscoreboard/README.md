# customscoreboard: Custom Scoreboard

Lets you place and scale the server's scoreboard sidebar like any HUD element. The editor shows a sample when the server sends none. ([ADR 0050](../../docs/adr/0050-first-modules-game-view.md))

| Setting | Kind | Default |
| --- | --- | --- |
| HUD: Scoreboard | position and scale | right, a unit in, 1x (the game's place) |

```sh
./gradlew :features:customscoreboard:check
```
