# shulkertooltips: Shulker Tooltips

A shulker box's tooltip shows its contents as a grid, on the box's color. ([ADR 0054](../../docs/adr/0054-screen-modules.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Box color | on/off | on |
| Only with Shift | on/off | off |

```sh
./gradlew :features:shulkertooltips:check
```
