# Whole-class changes to the vendor tree, applied before the patch files.
#
# A patch that deletes or rewrites a whole Mojang file would contain every one of its lines.
# A line here names the class and contains no Mojang code at all.
#
#   delete  <fully.qualified.ClassName>
#   replace <fully.qualified.ClassName>  <repo-relative path to Incari's replacement source>
#
# Only top-level classes; nested classes go with their outer class. Patches may not touch
# a class listed here: edit the replacement source instead.
