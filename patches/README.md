# Patches

Incari's changes to Minecraft's decompiled source. Generated by `./incari rebuild` from the commits
in `work/client`, and applied in order by `./incari apply`. **Never edit these files by hand.**

- `<subsystem>/<NNNN>-<slug>.patch`: one commit each. `NNNN` is the position in one global order
  (patches build on each other across subsystems); the folder groups them for review. The
  subsystem comes from the commit subject, `<subsystem>: <summary>`.
- `classes.txt`: whole classes deleted or replaced by Incari sources. These never go through a diff,
  so no Mojang lines end up in the repo.

Patches are written with one line of context (`-U1`) and no function names in hunk headers, to keep
the Mojang text in them to the minimum a patch needs in order to apply.

See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for the workflow.
